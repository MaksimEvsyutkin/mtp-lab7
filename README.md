## Описание проекта

В рамках лабораторной работы №7 «Работа с различными СУБД в Python» реализован комплексный программный модуль для взаимодействия с современными реляционными базами данных (**SQLite** и **PostgreSQL**). Проект демонстрирует как низкоуровневую работу с SQL-запросами и транзакциями через стандартную библиотеку `sqlite3` и драйвер `psycopg2`, так и высокоуровневое объектно-реляционное отображение (**ORM**) с использованием библиотеки **SQLAlchemy 2.0**.

## Выполненные задания (Вариант 2)

Согласно методическим указаниям для **варианта 2**, в полном объеме реализованы 3 задания средней сложности и 2 задания повышенной сложности:

### Задания средней сложности

1. **Задание №2: Вставить данные в таблицу**
   - Реализована параметризованная вставка данных через безопасные SQL-плейсхолдеры (`?`), исключающие возможность SQL-инъекций.
   - Методы `insert_department`, `insert_employee`, `insert_project`, `assign_employee` в модуле [`db/sqlite_raw.py`](db/sqlite_raw.py).
   - Поддерживается валидация входных данных (проверка на непустые строки, неотрицательные значения зарплат и бюджетов).

2. **Задание №4: Обновить запись**
   - Реализовано обновление данных существующих записей в базе данных с условием `WHERE`:
     - `update_employee_salary`: изменение оклада сотрудника с контролем корректности суммы;
     - `update_department`: динамическое обновление наименования и локации подразделения;
     - `update_project_budget`: обновление бюджета проекта.
   - Механизм проверки успешности операции через `cursor.rowcount > 0`.

3. **Задание №7: Создать несколько таблиц**
   - Спроектирована и создана реляционная схема базы данных, состоящая из 4 связанных таблиц:
     - `departments` (отделы компании: `id`, `name`, `location`);
     - `employees` (сотрудники: `id`, `department_id`, `full_name`, `email`, `salary`, `hire_date`, внешний ключ `FOREIGN KEY` к `departments`);
     - `projects` (проекты: `id`, `name`, `budget`);
     - `assignments` (таблица связи «многие-ко-многим»: `employee_id`, `project_id`, `role`, `hours` с каскадным удалением).
   - Активирован строгий контроль внешних ключей в SQLite (`PRAGMA foreign_keys = ON;`).

### Задания повышенной сложности

4. **Задание №2: CRUD через ORM (SQLAlchemy 2.0)**
   - В модуле [`db/models.py`](db/models.py) разработаны декларативные модели на базе современного синтаксиса `DeclarativeBase`, `Mapped`, `mapped_column` и `relationship`:
     - Модель `Department` с каскадным отношением к сотрудникам (`cascade="all, delete-orphan"`);
     - Модель `Employee` с ограничением `CheckConstraint("salary >= 0")`;
     - Модель `Project` с отношением многие-ко-многим к сотрудникам через ассоциативную таблицу `employee_projects`.
   - В модуле [`db/orm_crud.py`](db/orm_crud.py) реализован сервис `ORMService`, предоставляющий полный спектр CRUD-операций:
     - **Create**: создание отделов, сотрудников, проектов, назначение на проекты;
     - **Read**: выборка по первичному ключу, поиск по уникальному email, фильтрация сотрудников по отделу;
     - **Update**: обновление атрибутов объектов через контекст сессии SQLAlchemy;
     - **Delete**: удаление сущностей с соблюдением правил ссылочной целостности.

5. **Задание №6: Работа с PostgreSQL через psycopg2**
   - В модуле [`db/pg_client.py`](db/pg_client.py) реализован полнофункциональный клиент `PostgresClient` для взаимодействия с PostgreSQL.
   - Поддерживает:
     - Автоматическое создание целевой таблицы `pg_employees`;
     - Параметризованное добавление сотрудников с возвратом сгенерированного ID (`RETURNING id`);
     - Выборку данных с отображением строк в словари (`RealDictCursor`);
     - Обновление и удаление записей;
     - Настройку параметров подключения через переменные окружения (`PG_HOST`, `PG_PORT`, `PG_USER`, `PG_PASSWORD`, `PG_DB`).

## Инструкция по локальному запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/MaksimEvsyutkin/mtp-lab7.git
cd mtp-lab7
```

### 2. Создание и активация виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate   # macOS / Linux
# или .venv\Scripts\activate на Windows
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Запуск демонстрационного сценария
```bash
python3 main.py
```
Скрипт продемонстрирует создание связанных таблиц, параметризованную вставку данных, обновление записей, выполнение всех CRUD операций через SQLAlchemy ORM и работу клиента PostgreSQL.

## Непрерывная интеграция (CI)

В репозитории настроен автоматический CI-пайплайн GitHub Actions ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)):
- Запускает контейнер службы **PostgreSQL 15** (`postgres:15`) с проверкой готовности (`pg_isready`).
- Устанавливает зависимости из `requirements.txt`.
- Проверяет код линтером `flake8` на соответствие стандартам PEP 8.
- Выполняет весь набор тестов (`unittest`), включая **реальные интеграционные тесты против живой базы PostgreSQL**.
- Запускает демонстрационный скрипт `main.py`.
